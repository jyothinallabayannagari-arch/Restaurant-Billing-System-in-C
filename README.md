
Restaurant Billing System in C

A simple console-based restaurant billing system developed using C language.

Features

- Breakfast menu selection
- Tea & coffee menu
- Quantity-based bill calculation
- Cash, UPI, and card payment options
- Simple menu navigation

Technologies Used

- C Programming
- "switch-case"
- Loops
- Conditional statements
- "goto"

How to Run

1. Download or clone the repository.
2. Compile the C program using a C compiler.
3. Run the executable file.
4. Select menu options and enter quantities.
